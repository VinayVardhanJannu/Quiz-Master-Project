# 🎯 Java Quiz Master

An interactive quiz application designed to test programming knowledge through an engaging and user-friendly interface. The application combines a web-based frontend with Java-based backend logic.

## 🚀 Features

- Interactive welcome screen
- Programming and Java quiz questions
- 10 questions per quiz
- 20 seconds for each question
- Score tracking and total marks
- Clean and user-friendly interface
- HTML, CSS and JavaScript frontend with Java backend components

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java
- **IDE:** Eclipse
- **Version Control:** Git and GitHub

## ⚙️ How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project as an existing project.
4. Make sure the required Java JDK is configured.
5. Run `QuizServer.java` as a Java Application.
6. Open the frontend using `web/index.html` in a browser.

*Note: Check the server configuration and frontend API settings in the source files before running the application.*

## 🎓 Project Objective

The objective of this project is to develop an interactive quiz platform that helps users test their Java and programming knowledge while demonstrating practical skills in frontend development, Java programming and application integration.
